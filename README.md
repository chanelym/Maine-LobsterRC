# Slack Tide Lobster Shack Website

Slack Tide Lobster Shack is a static restaurant website built using HTML and CSS to showcase a seafood restaurant specializing in fresh Maine lobster. The website features a clean and visually appealing design that highlights the restaurant's menu, seafood offerings, and coastal atmosphere. Visitors can explore the restaurant's food options, learn more about the business, and navigate through different sections of the website. The project focuses on creating an organized and user-friendly restaurant website using HTML and CSS.

## Features

Navigation Menu: A simple navigation bar allowing visitors to explore different sections of the website.

Homepage: A landing page featuring the restaurant's branding, seafood imagery, and an introduction to Slack Tide Lobster Shack.

Restaurant Menu: A section showcasing the restaurant's seafood offerings and menu items.

Food Imagery: Features images of lobster and other seafood to highlight the restaurant's menu and create an appealing visual experience.

About Section: Provides visitors with information about the restaurant and its coastal-inspired atmosphere.

Buttons and Links: Styled buttons and navigation links that allow visitors to explore the website.

Responsive Design: Uses CSS to adjust the website layout for different screen sizes.

## Tech Stack
Frontend: HTML, CSS

## What I Learned

Using CSS to style different sections of a website, including backgrounds, images, buttons, and typography.

Creating navigation menus and styled links to improve the user experience.
